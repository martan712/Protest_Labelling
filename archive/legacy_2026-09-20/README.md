# Legacy material archived 2026-09-20

This directory contains data and model artifacts from the previous 21-class
keyword/annotation pipeline and the first `classifier_v2` experiment. It is
kept for provenance only; the active branch does not import from it.

- `data/`: old labels, manifests, predictions, and derived datasets.
- `models/`: old checkpoints and experiment outputs.

The old code, notebooks, and evaluation scripts were removed from this branch;
their exact versions remain available in Git history and on the other branches.
